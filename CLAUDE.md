# Brokeass Mafaka

Проект iPhone-приложения для личных финансов (учёт счетов, транзакций, бюджетов, планов, повторяющихся платежей). Задумано по функциональности как Debit & Credit для Mac. Приложение называется «Срудж Богдан». Есть код (пакет `LedgerCore`, приложение в `App/`, проект Xcode создаётся из `project.yml`). Это не git-репозиторий.

Владелец проекта не программист. Объясняй простыми словами, что делает приложение для пользователя, а не как устроен код.

## Документы

- `SPEC-ledger-iphone.md` — главное ТЗ для реализации (≈18 КБ): что наблюдалось в эталонном приложении, какое поведение повторить, предлагаемый дизайн.
- `iphone-app-design.md` — стек, модель данных, навигация, экраны (≈4 КБ).
- `debit-and-credit-mac-findings.md` — заметки по разбору эталонного Mac-приложения (≈11 КБ).

Читай только тот документ и раздел, который нужен для задачи. Начинай с `iphone-app-design.md`, он самый короткий.

## Правила проекта

Общие правила общения и экономии лежат в `~/.claude/CLAUDE.md`, здесь только специфика.

- Это чистая переделка по наблюдаемому поведению. Нельзя копировать код, ресурсы, иконки, тексты и название эталонного приложения. Нужны оригинальное имя, иконка и тексты.
- Предлагаемый стек: SwiftUI, iOS 17+, SwiftData (или Core Data), CloudKit для синхронизации, Charts, WidgetKit, App Intents.
- Бизнес-логику выноси в отдельный Swift-пакет `LedgerCore` без UI, чтобы её можно было тестировать.
- В ТЗ помечено, что неизвестно (знаки сумм, округление, значения периодов повтора и др.). Решения по ним принимай осознанно и фиксируй в тестах, не угадывай молча.
- Не запускай повторный анализ эталонного приложения (REA): выводы уже записаны в документах.
## Сборка и запуск

- Проект Xcode генерируется командой `xcodegen generate` из `project.yml`. Файл `SrudzhBogdan.xcodeproj` не править руками.
- Собирать нужно с `-derivedDataPath` вне папки Documents (например `/private/tmp/claude-501/dd15`) и тесты пакета запускать с `swift test --scratch-path /private/tmp/claude-501/ledger-build`: внутри Documents подпись падает из-за служебных меток macOS.
- Симулятор: iPhone 15 на iOS 26.5 (создан вместо тормозившего iPhone 18 Pro). Его id смотреть через `xcrun simctl list devices`.
- Для проверки с примерами данных запускать с аргументами `-seedDemo -baseCurrency BYN` (работает только в отладочной сборке, код в `App/Support/DemoData.swift`).
- Онбординг в отладочной сборке: `-onbDemo` заполняет ответы примерами, `-onbStep N` (0...8) открывает нужный шаг (код в `App/Support/DemoData.swift`). Запускать через `xcrun simctl launch`, на чистой установке (`simctl uninstall`).
- Кириллицу в поля симулятора лучше не вводить через инструмент (вставка портит текст и просит разрешение), названия для проверки писать латиницей.
- Тексты интерфейса только через ключи в `App/Localizable.xcstrings` (русский и английский). Новый текст: добавить ключ в оба языка.

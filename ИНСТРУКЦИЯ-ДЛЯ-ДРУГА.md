# Как поставить «Срудж Богдан» на iPhone

Делается один раз, дальше достаточно запускать файл снова раз в неделю (бесплатная подпись Apple живёт 7 дней). Данные в приложении при этом сохраняются.

## Подготовка (один раз)
1. Поставь **Xcode** из App Store и открой его один раз (согласись с лицензией, дождись установки доп. компонентов).
2. В Xcode: **Settings → Accounts → «+» → Apple ID**, войди в свой Apple ID (платный аккаунт не нужен).
3. На iPhone включи **Режим разработчика**: Настройки → Конфиденциальность и безопасность → Режим разработчика (телефон перезагрузится).
4. Подключи iPhone кабелем, разблокируй, нажми «Доверять».

## Установка
1. Открой Терминал и выполни (путь к файлу подставь свой, можно перетащить файл в окно):
   ```
   bash ~/Downloads/Установить-Срудж-Богдан.command
   ```
2. Первая сборка занимает до 5 минут. Если спросит Team ID, скрипт сам объяснит, где его взять.
3. Если приложение не открылось: на iPhone Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.

## Обновление
Получишь новый файл, запусти так же. Всё поставится поверх, данные останутся.

## Если не работает
Скрипт пишет понятную причину. Если не помогло, пришли владельцу текст из окна терминала.
